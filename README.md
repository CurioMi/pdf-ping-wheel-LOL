# PDF Ping Wheel

**PDF Ping Wheel** 是一个面向 Chrome / Edge 的本地 PDF 标注扩展。它把游戏式快捷操作带入 PDF 阅读：快速放置信号、表情、亮牌和聊天式备注，并将标记保存为 PDF 原生 `/Stamp` 注释。

> 当前源码版本：**v1.9.1 · 阶段冻结版**。这是独立的玩家风格工具，不是 Riot Games 官方产品，也未获 Riot Games 背书。

阶段冻结版支持 Chrome / Edge。直接写入前会核对原件内容，如果另一处已改过原文件，阅读器会另存一份阅读副本。以下载方式导出时，本机暂留导出改动；即使取消下载，重开同一份原件仍可恢复。重新打开已导出的确切副本后，对应的临时恢复记录会清理。

## 开始阅读

打开或拖入一篇 PDF，顶部可以直接打开另一篇、保存、写论文笔记或看巡灯进度。重新打开同一篇会回到上次读的位置。「工具」里有缩放、标记大小、文献疑问、静读和战利品。默认按阅读区宽度显示。手动放大看图后，点「工具 → 适应宽度」可以恢复。常用快捷键在正文中照常使用。

## 同行伙伴与任务标识

在 PDF 顶部点伙伴或小灯，进入「巡灯与任务」就能换伙伴。新存档从一枚小火龙蛋开始。已有存档沿用巡灯，可以随时选择伙伴，也可以选「只显示巡灯」。

| 同行伙伴 | 一层从哪里来 | 长大时的样子 |
|---|---|---|
| 小火龙 · 斯莫德 | 每累计 5 分钟有效阅读 | 第 1 层破壳，第 5 层展翼，第 15 层吐焰 |
| 铸星龙王 · 奥瑞利安·索尔 | 每累计 10 分钟有效阅读得 1 层星尘。每个文献页首次保存标记再得 1 层 | 第 1 层初星，第 6 层星轨，第 18 层星冠 |
| 黑暗收割 | 每首次保存一个已解决的不同问号，得 1 层灵魂 | 第 1 层魂火，第 3 层双焰，第 8 层幽冠 |

三条路线都按已经记录的活动计算。无论展示哪一条，换篇、跨天、换伙伴都能接着积累，最终形态后层数仍会增加。三枚小标识依次对应今日读满 10 分钟、在 3 个不同页面保存标记、回访 1 个疑问。空心图形旁的小点表示进行中，勾表示已完成。把鼠标停在图标上或点开伙伴，就能看见具体进度。标识只出现在阅读栏。

## 论文笔记

打开一篇 PDF，点阅读栏的「论文笔记」。在空白的「整篇心得」里写自己的总结。读到某个公式或图表时，点「＋ 记当前页」写一条页边笔记。点列表里的笔记会回到记录时的位置，可以继续修改或删除。收起侧栏后，正文上不会多出图标。扫描版也能用。

输入的文字会按文献暂存在本机。点工具栏「保存」把笔记写入 PDF，再用本扩展打开保存后的文件即可接着写。要在其他软件里看或整理文字，可点侧栏的「导出笔记 .txt」，得到整篇心得和按页码排列的记录。笔记没有字数任务。

## 峡谷巡灯

打开文献照常阅读，累计每 10 分钟自动点亮一处地标。今天读 6 分钟，明天再读 4 分钟，就能点亮第一盏灯。点击阅读栏的伙伴或小灯，或进入战利品的「巡灯与任务」，能看到守灯人走过的路和每处地标的手记。四盏走完一程，萤溪谷、薄雾山径和星落原野三条路线依次轮换。旧存档已有的有效阅读时间也算在内。每个已结算的疑问回访还会添一颗星。地图最多绘出 12 颗，星数超过 12 时仍保留完整计数。

普通阅读两分钟无操作会暂停。遇到公式或长段落，在「工具」里点「静读 10 分钟」，这篇 PDF 在前台时可以静静读，最多累计十分钟。离开窗口或打开战利品会暂停，回来继续。提前结束、换篇或刷新后，已记入的时间保留，普通计时恢复。任务完成后奖励自动到账，伙伴或小灯旁的奖励提示可以稍后查看。

## 问号备注与标记大小

用 Alt 信号轮盘放下问号，点击问号即可在页边展开「疑问备注」和「我的理解」。再次点击问号或点「收起」，页面只留下图标。窄窗口会把备注放在阅读区下方。「工具」里的「文献疑问」可切换本篇的问号并定位到原文。两栏都填写后可以标为已解决，点击「保存」会把备注、解答和状态一起写入 PDF。支持注释的阅读器可以从该图章的评论内容读取文字。

新图标默认小号。「工具」里的「小 / 中 / 大」分别为原图标边长的 50%、75%、100%。选中信号、表情或亮牌时，还会调整该标记。原有标记保留原尺寸，普通文字备注按正文排版。浏览器会记住新标记的默认尺寸。

未写入 PDF 的标注及正在输入的备注保存在本机浏览器的文献草稿中，重新打开同一篇文献可以恢复，并返回上次阅读位置。进入战利品再返回可接着输入。切换文献时会提示未保存的改动。需要跨设备携带问号备注时，请保存 PDF；普通聊天草稿要先按 Enter 放置。「疑问回访」每天可获得 25 XP，同一个已解决问号只结算一次。

## 战利品与阅读成长

打开 **工具 → 战利品** 即可更换表情。

- **2,423 个表情**：完整目录快照，包含英雄联盟与云顶之弈系列；支持中英文、编号搜索，以及已拥有/未解锁/收藏/已装备筛选。
- **自定义九格轮盘**：先选位置，再点击装备；也可把卡片拖到轮盘上。中心位对应轻点 T，外圈八格对应按住 T 选择，配置自动保存。
- **研究宝箱**：完成任务或升级获得宝箱，打开后从三个未拥有的表情中任选一个。也能用 100 研究精粹定向兑换喜欢的表情。
- **阅读任务**：有效阅读 10/25 分钟、在三个不同页面保存标记、写下三条不同的聊天式备注，均有奖励；另有长期里程碑。后台、休眠和查看战利品时暂停计时。普通阅读空闲两分钟后也会暂停。
- **本地成长存档**：初始九表情、300 精粹和一个宝箱；支持存档导出/导入。自由模式可直接装备全部表情，任务进度照常保留。

任务的奖励、计时与去重规则，以及对 LOL 客户端的设计参考，见 [阅读峡谷设计](GAMEPLAY_DESIGN.md)。计时只能反映本地活动，不会判断是否理解论文。当前表情库为构建时快照，后续新增表情需更新安装包。

## 功能

- **信号轮盘**：按住 `Alt` 并移动鼠标选择信号；`G` 放置普通信号，`V` 放置危险／撤退信号，`H` 放置敌方有视野标记。
- **表情轮盘**：按住 `T` 并移动鼠标选择表情；轻点 `T` 可放置中心表情。
- **亮牌**：`Ctrl+6`；如果浏览器拦截快捷键，可在「工具」中点击「亮牌」。
- **聊天式备注**：按 `Enter` 打开，按 `Enter` 发送，`Shift+Enter` 换行，`Esc` 关闭。
- **原生 PDF 注释**：标记可移动、删除；备注可双击编辑。保存后重新打开 PDF，仍可读取标记及备注。
- **本地处理**：PDF 内容在本机处理，扩展不会主动上传用户的 PDF。
- **游戏素材**：v1.9.1 完整素材包包含 9 种游戏信号图标与提示音、2,423 个表情和 1 个亮牌图标；源码仓库不直接提交这些游戏资产。未安装素材时，初始九表情仍有回退图标，新表情在藏品库提示需安装完整素材。

## 安装和运行

### 方式 A：使用预构建扩展

1. 从项目的 **Releases** 下载 Chrome / Edge 扩展 ZIP（如果尚无 Release，请使用方式 B 本地构建）。
2. 解压文件。
3. 打开 `chrome://extensions` 或 `edge://extensions`，启用“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `dist/` 文件夹。

### 方式 B：从源码构建

要求 Node.js 22 或更高版本。克隆仓库后运行：

```bash
npm install
npm run assets:install # 可选：下载完整离线素材，约 161 MB 表情图片
npm run build
npm run verify
npm run verify:static
npm run verify:pdf
npm run verify:progression
```

构建完成后，在浏览器扩展管理页加载项目根目录下生成的 `dist/` 文件夹。

## 快捷键

| 操作 | 快捷键 |
|---|---|
| 普通信号 | `G` |
| 危险／撤退信号 | `V` |
| 敌方有视野标记 | `H` |

问号信号位于信号轮盘中，不设置额外的独立默认热键。

## 自定义素材

GitHub 源码仓库不直接保存原版游戏素材。运行 `npm run assets:install` 可按已提交目录快照下载并校验信号、音效、完整表情和亮牌；维护者可用 `npm run assets:sync` 刷新表情目录并下载新增图片，再重新构建。也可将有权使用的替换文件放入 `public/riot/` 对应目录。

- `textures/`：信号 PNG 图像
- `sounds/`：信号 WAV 音效
- `emotes/`：表情 PNG 图像
- `mastery/`：亮牌 PNG 图像

素材文件名可参考 `src/pings.js` 和 `public/riot/ASSET_MAP.json`。扩展运行时不会从远程网站加载游戏素材；所有已打包素材均从本地文件读取。

完整表情目录及来源校验信息见 `src/emote-catalog.json`。`public/riot/emotes/catalog-index.json` 由完整下载校验后生成。表情素材采用按需加载，PDF 只嵌入实际用到的图片。

浏览器回归测试：安装 Playwright 的 Chromium（`npx playwright install chromium`）后运行 `npm run verify:ui`。也可设置 `BROWSER_BIN` 使用本机 Chromium 系浏览器。测试在独立资料目录运行，不使用日常浏览器存档。

## PDF 保存格式

- 每个标记以标准 PDF `/Subtype /Stamp` 注释保存，并带有 `/AP /N` 外观流。
- 插件使用自定义注释元数据和唯一 ID 恢复编辑状态；位置和删除状态以 PDF 注释对象为准。
- 备注正文写入注释 `/Contents` 与插件元数据，并由本地文字渲染为可见外观。标准阅读器可以显示和打印备注，但备注的可见文字目前不是 PDF 正文中可直接选择的文本。
- 仍支持读取部分旧版本 PDF 标记格式。对重要文档操作前请备份原文件。

不同 PDF 阅读器对注释选择、移动、打印和自定义字段的保留行为可能不同。发布前建议在 Chrome、Edge 和 Adobe Acrobat 中进行实际验证。

## 目录结构

```text
src/                    核心业务逻辑
public/                 扩展 manifest、图标与素材占位目录
scripts/                构建、检查和 PDF 回归测试
branding/               原创应用图标源文件和多尺寸图标
dist/                   本地构建输出（不提交到源码仓库）
.github/workflows/      CI 构建与验证
```

后续开发请优先修改 `src/`、`public/` 和 `scripts/`，不要直接修改生成后的 `dist/assets/viewer.js`。版本记录见 [CHANGELOG.md](CHANGELOG.md)。
