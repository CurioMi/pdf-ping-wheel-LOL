# PDF Ping Wheel v1.6.0 安装与升级说明 | Installation & Upgrade Guide

## 中文说明

### Chrome / Edge 安装

1. 使用本次交付的安装包，或在版本发布后从 [GitHub Releases](https://github.com/CurioMi/pdf-ping-wheel-LOL/releases) 下载 `PDF_Ping_Wheel_Chrome_v1.6.0.zip` 并解压到一个固定文件夹。
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压目录中包含 `manifest.json` 的 `PDF Ping Wheel v1.6.0/dist` 文件夹。
5. 加载成功后，打开 PDF 即可使用。

### 本版本包含的游戏素材

正式安装包预置 9 种游戏信号图标与对应提示音、2,423 个游戏表情和 1 个亮牌图标。安装后无需另外下载素材。游戏素材属于 Riot Games 及／或其相应权利人，不属于本项目的 MIT 源码许可证。

### 升级

1. 在战利品界面点击“导出存档”备份收藏、轮盘和任务进度。
2. 将新版文件覆盖到原先加载的固定文件夹，然后在扩展管理页面点击“重新加载”。
3. 如果更换文件夹或重新安装导致扩展 ID 改变，原存档可能不可见；在新版本战利品界面点击“导入存档”恢复。

### 自定义素材

你可以替换 `dist/riot/` 下的 `textures/`、`sounds/`、`emotes/` 和 `mastery/` 对应文件。素材文件名可参考 `src/pings.js` 与 `public/riot/ASSET_MAP.json`。替换后请在浏览器扩展管理页重新加载扩展，并确保你有权使用这些素材。

## English Instructions

### Install on Chrome / Edge

1. Download `PDF_Ping_Wheel_Chrome_v1.6.0.zip` from the delivered build, or from [GitHub Releases](https://github.com/CurioMi/pdf-ping-wheel-LOL/releases) after publication and extract it to a permanent folder.
2. Open `chrome://extensions` in Chrome or `edge://extensions` in Microsoft Edge.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the `PDF Ping Wheel v1.6.0/dist` folder containing `manifest.json`.
5. Once loaded, open a PDF to start using the extension.

### Game Assets Included

This release bundles nine in-game ping icons and their sound effects, 2,423 emote images, and one mastery icon. No separate asset download is needed. These game assets belong to Riot Games and/or their respective rights holders and are not covered by this project's MIT source-code license.

### Upgrade

1. Export your profile from the Loot screen before upgrading.
2. Replace the files in the existing extension folder, then click **Reload** on the extensions page.
3. Changing the folder or reinstalling may change the extension ID. Import your profile backup in the new Loot screen to restore progress if necessary.

### Custom Assets

You may replace files in `dist/riot/textures/`, `dist/riot/sounds/`, `dist/riot/emotes/`, and `dist/riot/mastery/`. Refer to `src/pings.js` and `public/riot/ASSET_MAP.json` for expected filenames. Reload the extension after replacing files, and ensure you have the right to use the assets.
