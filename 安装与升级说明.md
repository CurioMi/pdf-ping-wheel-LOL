# PDF Ping Wheel v1.5.2 安装与升级说明 | Installation & Upgrade Guide

## 中文说明

### Chrome / Edge 安装

1. 从 [GitHub Releases](https://github.com/CurioMi/pdf-ping-wheel-LOL/releases) 下载扩展 ZIP，并解压到一个固定文件夹。
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
3. 开启“开发者模式”（Developer mode）。
4. 点击“加载已解压的扩展程序”（Load unpacked），选择解压目录中包含 `manifest.json` 的 `dist/` 文件夹。
5. 加载成功后，打开 PDF 即可使用扩展。

### 升级

1. 下载新版 ZIP 并解压到一个固定的新文件夹。
2. 在扩展管理页面找到 PDF Ping Wheel，点击“重新加载”（Reload），或先移除旧版本再加载新版本的 `dist/` 文件夹。
3. 如果更换了扩展所在的文件夹，浏览器可能会将它视为新的扩展加载路径；请确认加载的是正确的 `dist/` 文件夹。

### 自定义素材

公开仓库和发布 ZIP 不包含 Riot Games 原版图片或音效，也不附带自动下载脚本。如果你有权使用本地素材，可手动复制到 `dist/riot/` 下的 `textures/`、`sounds/`、`emotes/` 和 `mastery/` 对应目录。素材文件名可参考源码中的 `src/pings.js` 与 `public/riot/ASSET_MAP.json`。添加素材后，请在扩展管理页重新加载扩展。

### 注意事项

- 这是一个独立的非官方项目，与 Riot Games 没有隶属、授权或背书关系。
- PDF 在本地处理；扩展不会主动上传你的 PDF 文件。
- 不同 PDF 阅读器对注释的显示和打印支持可能不同。重要文件请先备份。

## English Instructions

### Install on Chrome / Edge

1. Download the extension ZIP from [GitHub Releases](https://github.com/CurioMi/pdf-ping-wheel-LOL/releases) and extract it to a permanent folder.
2. Open `chrome://extensions` in Chrome or `edge://extensions` in Microsoft Edge.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the `dist/` folder that contains `manifest.json`.
5. Once the extension is loaded, open a PDF to start using it.

### Upgrade

1. Download the new ZIP and extract it to a permanent folder.
2. On the browser extensions page, find PDF Ping Wheel and click **Reload**. Alternatively, remove the old unpacked extension and load the new version's `dist/` folder.
3. If you move the extension to a different folder, the browser may treat it as a different unpacked-extension path. Make sure you load the correct `dist/` folder.

### Custom Assets

The public source repository and release ZIP do not include original Riot Games images or sounds, and they do not provide an automatic asset downloader. If you have the rights to use local assets, copy them manually into the corresponding folders under `dist/riot/`: `textures/`, `sounds/`, `emotes/`, and `mastery/`. Refer to `src/pings.js` and `public/riot/ASSET_MAP.json` for expected filenames. Reload the extension from the browser's extensions page after adding assets.

### Notes

- This is an independent, unofficial project and is not affiliated with, authorized by, or endorsed by Riot Games.
- PDF files are processed locally; the extension does not actively upload your PDFs.
- PDF annotation display and printing may vary between PDF readers. Back up important files before use.
